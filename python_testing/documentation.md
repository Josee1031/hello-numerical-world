# Python Testing Scripts Documentation

## Overview

This documentation provides an overview of three Python testing scripts used to validate heat conduction solutions under different boundary conditions and initial conditions. Each script compares computed results against expected values, checking for deviations beyond a specified error boundary.

## Scripts

### 1. `check_lss.py`

#### Description
The `check_lss.py` script validates the linear steady state equation for heat conduction based on given boundary conditions. The script ensures that the computed values conform to the expected linear relationship within a specified error tolerance.

#### Functionality
- **Input Handling**: Reads input from a specified file containing x and y values.
- **Boundary Conditions**: Accepts boundary conditions (bc0 and bc1) and length (Len) as arguments.
- **Error Tolerance**: Uses absolute error by default; switches to relative error if a negative error bound is specified.
- **Validation**:
  - Checks the value at `x = 0` against the left boundary condition (bc0).
  - Computes the expected y value for other x values based on the linear equation derived from the boundary conditions.
  - Compares the computed y values against the expected y values, ensuring the differences are within the specified error tolerance.

### 2. `impulse_solution.py`

#### Description
The `impulse_solution.py` script checks the solution of the heat equation by comparing it with an impulse condition generated by heat. The script verifies that the computed x and y coordinates match the expected values within a specified error boundary.

#### Functionality
- **Input Handling**: Reads input from a specified file containing x and y values.
- **Impulse Condition**: Compares the computed results against an array of expected values generated by the impulse condition.
- **Error Tolerance**: Checks for differences between the computed and expected values, ensuring they do not exceed the specified error boundary.
- **Validation**:
  - Iterates through the x and y coordinates from the input file.
  - Compares each coordinate pair against the corresponding expected value from the impulse condition array.
  - Flags any discrepancies beyond the error tolerance and reports the details.

### 3. `sinusoidal_solution.py`

#### Description
The `sinusoidal_solution.py` script validates the solution of the heat equation by comparing it with a sinusoidal condition generated by heat. The script ensures that the computed x and y coordinates align with the expected sinusoidal values within a specified error boundary.

#### Functionality
- **Input Handling**: Reads input from a specified file containing x and y values.
- **Sinusoidal Condition**: Compares the computed results against an array of expected values generated by the sinusoidal condition.
- **Error Tolerance**: Checks for differences between the computed and expected values, ensuring they do not exceed the specified error boundary.
- **Validation**:
  - Iterates through the x and y coordinates from the input file.
  - Compares each coordinate pair against the corresponding expected value from the sinusoidal condition array.
  - Flags any discrepancies beyond the error tolerance and reports the details.

## Error Tolerance

All three scripts use a configurable error tolerance to determine the acceptable deviation between computed and expected values. By default, an absolute error is used, but relative error can be specified by providing a negative error bound.

## Usage

Each script requires the following arguments:
1. Input file containing x and y values.
3. Additional parameters for boundary conditions or specific conditions (impulse or sinusoidal).

These scripts are executed as part of a GitHub Actions pipeline and are invoked through the `make check` command in the Makefile.
